VOIDX maps a web target and reports only what it can prove. DNS, TLS, headers, technologies, crawl, forms, cookies, exposed files, JavaScript and APIs are all collected, and every finding ships with its evidence, a confidence level, the detection method and the affected URLs.
---

## 📌 **Installation & Execution**

### **1️⃣ Clone the Repository**
```bash
git clone https://github.com/VDIXA0/voidx.git
```

### **2️⃣ Navigate to the Project Folder**
```bash
cd voidxy
```

### **3️⃣ Install Dependencies**
```bash
pip install -r requirements.txt
```

### **4️⃣ Make the Script Executable**
```bash
chmod +x voidxy.py
```

### **5️⃣ Run the Tool**
```bash
python3 voidxy.py
```

---

## 📂 **Run from Desktop**
If you want to place and run the tool from your **Desktop**, use:  
```bash
mv voidx ~/Desktop/
cd ~/Desktop/voidxy
python3 voidxy.py
```

---

## ⚠️ **Notes**
- If you get a `Permission Denied` error, try:  
  ```bash
  sudo python3 voidxy.py
  ```
- If `git` is missing, install it:  
  ```bash
  sudo apt install git -y
  ```
- If `pip` is missing, install it:  
  ```bash
  sudo apt install python3-pip -y
  ```
